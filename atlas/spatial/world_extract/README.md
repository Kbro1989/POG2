# `atlas/spatial/world_extract`

Raw world tile extracts for consecutive map regions.

## Contents

| File | Purpose |
|------|---------|
| `ms_49_50.json` | Region 49_50 world fragment |
| `ms_50_50.json` | Region 50_50 world fragment |

## Usage

Feed these into `CacheSpatialDecoder` / `SpatialDecoder` to reconstruct ground truth for specific map chunks.
