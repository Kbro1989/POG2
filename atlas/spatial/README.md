# Atlas / Spatial

Game-world spatial data used by atlas/mapping systems.

## Files

- `barrows_logic.json` — Barrows city anchors, bounds, and collision matrix.
- `m_55_50_logic.json` — Map-square logic for coordinates around (55, 50).
- `raw_discovery_8755.json` — Raw discovery output for exploration id `8755`.
- `unified_extract/ms_49_50.json` — Unified spatial extract for map square (49, 50).
- `world_extract/ms_49_50.json` — World extract for map square (49, 50).
- `world_extract/ms_50_50.json` — World extract for map square (50, 50).

## Usage

Spatial files are JSON. They describe anchors, bounds, collision, and raw discovery data used by the world-atlas pipeline.
