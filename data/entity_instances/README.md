# Data / Entity Instances

NPC definition dumps used for entity instantiation and combat simulation.

## Files

- `npc_definitions.json` — Raw NPC definition dump from cache extraction.
- `npc_definitions_padded.json` — Padded/aligned NPC definition entries for stable indexing.

## Usage

These files populate the entity registry and drive NPC combat stats, drops, and spawn behavior in the POG2 engine.
