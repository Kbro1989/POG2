# Data / PVME

Player vs Monster Engine rotation data for high-level PvM bosses.

## Files

- `araxxi.json`
- `kerapac__the_bound.json`
- `nex.json`
- `raksha__the_shadow_colossus.json`
- `solak.json`
- `telos__the_warden.json`
- `vorago.json`

## Structure

JSON with `bestiary` metadata and `rotations` arrays keyed by team size/section.

## Usage

Feeds the POG2 combat rotation engine and ability-damage simulation.
