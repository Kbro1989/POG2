# `src/limbs/metaphysical`

Meta-layer limbs — transcendent / over-game systems (omega states, ghost entities, relics, quantum).

## Contents

| File | Purpose |
|------|---------|
| `OmegaLimb.ts` | Omega-state evaluator — highest-authority decision node for meta-game actions. |
| `GhostLimb.ts` | Ghost-entity proxy; represents entities that have "left" but retain state. |
| `RelicLimb.ts` | Manages persistent cross-session relics and their state transitions. |
| `QuantumLimb.ts` | Quantum-probability resolver for stochastic game events. |

## Usage

These limbs sit above the combat and spatial layers; they are invoked by the
`TemporalHeartbeatLimb` and `HexagramNetworkBridge` when evaluating meta-transitions.
