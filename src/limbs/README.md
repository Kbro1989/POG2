# `src/limbs`

Modular capability units ("limbs") that together form the POG2 brain.

Each limb is an independent TypeScript module registered through the `HexagramNetworkBridge`
and activated by the `TemporalHeartbeatLimb` on its canonical clock.  
Sub-modules: `audio`, `cognitive`, `combat`, `core`, `creative`, `gameplay`, `logical`,
`metaphysical`, `pedagogy`, `sensory`, `spatial`, `system`, `technical`, `vision`,
`voice`, `world_grounding`.
