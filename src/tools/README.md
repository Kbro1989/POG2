# src/tools

Operational/dev runnables for data, model bridging, and geometry authoring.

- `annotate_geometry.ts` — Interactive TUI for tagging collision/geometry regions; promotes resolved annotations into sovereign assumptions.
- `ollama_tier_bridge.ts` — Tool definition bridging cognitive tasks to local Ollama hardware through tiered model routing.
- `seed_gal.ts` — Seeds geometry annotation-layer state.
- `explore_cutscenes.ts` — Cuts through/interprets cutscene data.

Run / test: run directly, e.g. `npx tsx src/tools/annotate_geometry.ts`.
