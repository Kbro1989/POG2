# src/state

Session and systemic state tracking.

- `StateManager.ts` / `.js` — Singleton sovereign process state: mode, workspace, session id, and rolling metrics.
- `NeurologicalMap.ts` / `.js` — CNS/PNS/sensory/system node registry mapping code paths to biological metaphor roles, domains, and metabolic costs.

Run / test: consumed by boot/monitor/routing; no standalone entrypoint.
