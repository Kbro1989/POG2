**Most likely causes:**

| Symptom | Cause | Fix |
|---|---|---|
| `null` return, no console output | `searchBeasts` not called | Check `ApiThrottle.acquire('bestiary')` — wrong domain name |
| `null` return, `404` status | Proxy route missing | Add `/api/bestiary/*` route to Cloudflare Worker |
| `null` return, `[]` data | Jagex API changed | Verify `services.runescape.com` endpoint still live |
| `null` return, network error | CORS or connectivity | Test `curl` directly from your machine |
