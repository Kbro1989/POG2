**[GeApi.ts](sandbox:///mnt/agents/output/GeApi.ts)** — Complete dual-source GE API client.

Key features implemented:

| Feature | Implementation |
|---|---|
| **Dual-source** | Weird Gloop primary → Jagex proxy fallback |
| **Price parser** | `parsePrice("5.2m")` → `5200000`, handles k/m/b + commas |
| **Members string→bool** | `"true"` → `true`, `"false"` → `false` |
| **Trend normalization** | `positive`→`rising`, `negative`→`falling`, `neutral`→`neutral` |
| **ApiThrottle** | Separate buckets for `weirdgloop` and `jagex_ge` |
| **History** | 180-day daily + average from both sources |


**Critical:** The graph endpoint has a different URL pattern (`/api/graph/{id}.json` not `/api/catalogue/graph.json`). Your proxy needs special handling for this.
