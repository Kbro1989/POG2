Actually, looking at the code, both meshes use the same `geometry` variable. The current `dispose()` calls `this.walkableMesh.geometry.dispose()` and `this.blockedMesh.geometry.dispose()` — that's the same geometry object disposed twice. **This will crash.**

## Corrected dispose()

```typescript
public dispose() {
    // Geometry is shared between both meshes — dispose once
    const geometry = this.walkableMesh.geometry;
    geometry.dispose();
    
    // Materials are unique per mesh
    (this.walkableMesh.material as THREE.Material).dispose();
    (this.blockedMesh.material as THREE.Material).dispose();
    
    this.scene.remove(this.walkableMesh);
    this.scene.remove(this.blockedMesh);
}
```
