## Coordinate Conversion Formulas

**Developer → Map coordinates:**
```
mapX = (x1 * 64) + x2
mapY = (y1 * 64) + y2
```
Where:
- `x1, y1` = mapsquare (e.g., 50, 50 for Lumbridge)
- `x2, y2` = local tile within mapsquare (0-63)
- Result: absolute world coordinates

**Example:**
- Dev: `50, 50, 32, 32` (Lumbridge center)
- Map: `(50 * 64) + 32 = 3232`, `(50 * 64) + 32 = 3232`

**Cache integer format:**
```
packed = (z << 28) | (x << 14) | y
```
Or reverse:
```
z = packed >> 28
x = (packed >> 14) & 0x3FFF
y = packed & 0x3FFF
```
