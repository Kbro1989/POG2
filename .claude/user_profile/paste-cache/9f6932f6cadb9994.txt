## The `rsmvBridge` Critical Question

Line 1: `import { rsmvBridge } from '../utils/RSMVBridge.js'`

If this is the **same RSMVBridge** from the browser client (WebSocket to DO), then `SovereignEntityResolver` is **client-side code masquerading as server-side**. It will fail in the DO.

If it's a **server-side cache reader**, it needs to look like:

```typescript
// Server-side RSMVBridge:
class RSMVBridge {
    constructor(private env: { R2: R2Bucket, KV: KVNamespace }) {}
    
    async getNpc(id: number) {
        // Read from R2 cache dump or KV
        return this.env.KV.get(`npc:${id}`);
    }
}
```

**Which is it?** The agent needs to clarify before this compiles.

## The `manifestData` Import Path

```
src/
  services/
    SovereignEntityResolver.ts  ← you are here
  utils/
    RSMVBridge.ts
public/
  authentic_spawn_manifest.json  ← target
```

From `src/services/`, `../../public/` = `public/` — **if** the build tool (Vite/webpack) allows importing from `public/`. Most don't — `public/` is for static assets, not bundled modules.

**Fix options:**
- **A)** Copy manifest to `src/assets/` at build time
- **B)** Use dynamic `fetch()` to load from `public/` at runtime
- **C)** Configure build tool to allow `../../public/` imports
