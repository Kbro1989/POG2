**2. `getBeastsByArea` identifier formatting**

Your implementation:
```typescript
const identifier = area.replace(/\s+/g, '+');
const url = `${this.BASE}/areaBeasts.json?identifier=${encodeURIComponent(identifier)}`;
```

This double-encodes the `+`. `encodeURIComponent('+')` → `%2B`, but the API expects literal `+` for spaces. The canonical spec says:

> "where X is any area in the areaNames query, with spaces replaced by + signs"

So either:
```typescript
// Option A: Don't encodeURIComponent the identifier
const identifier = area.replace(/\s+/g, '+');
const url = `${this.BASE}/areaBeasts.json?identifier=${identifier}`;

// Option B: Use encodeURIComponent on raw area, then replace encoded spaces
const url = `${this.BASE}/areaBeasts.json?identifier=${encodeURIComponent(area).replace(/%20/g, '+')}`;
```

Option A is cleaner. `encodeURIComponent` is unnecessary here since you're manually replacing spaces with `+` and area names don't contain other special characters that need encoding.

**Fix:**
```typescript
static async getBeastsByArea(area: string): Promise<BeastSearchResult[]> {
    await this.THROTTLE.acquire('bestiary');
    const identifier = area.replace(/\s+/g, '+');
    const url = `${this.BASE}/areaBeasts.json?identifier=${identifier}`;  // No encodeURIComponent
    // ...
}
```
