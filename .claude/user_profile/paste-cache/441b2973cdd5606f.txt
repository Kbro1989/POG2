### Low: UV values in `kit_12428.json` are large integers (13111, 47411, etc.)

These look like fixed-point or packed UV coordinates, not normalized [0,1] floats. Babylon.js expects normalized UVs. If these are passed directly to the renderer, texture mapping will be broken.

**RS3 convention:** UVs are often stored as 16-bit fixed-point (divide by 65536 or similar). The values 13111, 47411, 53307 suggest a scale factor around 65536 (13111/65536 ≈ 0.20, 47411/65536 ≈ 0.72). 

**Fix:** In `buildBetaOpcoder()`, divide UV values by 65536.0 (or the correct fixed-point scale for format 2 version 5) before serializing.
