**Critical implementation notes:**

1. **The `searchBeasts` OR behavior is handled** — `resolveId("Abyssal demon")` will return `1615` despite `searchBeasts` also returning Abyssal leech (2263), guardian (2264), etc. The exact-match filter strips `(98)` suffixes before comparison.

2. **Members override is automatic** — Any beast with `slayerlevel > 0` and `members === false` gets corrected. This covers Abyssal demon, all slayer bosses, and most high-level content.

3. **Slayer category warning is logged** — `getBeastsBySlayerCategory()` emits `[INCOMPLETE warning]` in logs per Jagex's own documentation.

4. **Area identifier formatting** — `getBeastsByArea("The Abyss")` correctly converts to `identifier=The+Abyss` for the API.
