# Mediator

UI and integration layer between the POG2 engine and external consumers.

## Contents

- `app/components/Model3DViewer.tsx` — React/Three.js component that loads RS3/OSRS cache models via `Openrs2CacheSource` and renders them with orbit controls.

## Usage

Start the `mediator` app to provide the 3D model preview surface consumed by the engine/hud.
