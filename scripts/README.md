# scripts

Standalone operational scripts for POG2 extraction, analysis, and training.

Mix of TypeScript, JS, Python:
- Extraction/decode: `direct_pog2_extract.ts`, `decode_kinematics.ts`, `extract_directional_collision.ts`, `extract_cache_logic.ts`, `refactored_extract_1430.ts`
- Cache/forensics: `cross_reference_cache.py`, `enum_forensics.ts`, `discover_collision_rules.ts`
- Bestiary/scrape: `scrape_bestiary.py`, `analyze_interface_connections.js`
- Grounding/UI/sovereign: `grounding_decoder.ts`, `ground_ui_blueprint.ts`, `ground_sovereign_substrate.ts`
- Training/finetune: `train_unsloth.py`, `fireworks_finetune.py`
- Integration/tests: `test_immunology_integration.mjs`, `logic_joiner.ts`, `spatial_bridge_heatmap.ts`, `cleanup_screenshots.cjs`, `synthesize_barrows_logic.ts`

Run from repo root; many depend on local cache/data paths.
