# Generated

Auto-generated TypeScript type definitions from POG2 opcode/cache JSON schemas.

## Contents

- `*.d.ts` — Ambient type declaration files (`typedef`, `structs`, `npcs`, `items`, `mapsquare_*`, `enums`, `dbtables`, `clientscript`, `sequences`, etc.).
- `maprenderconfig.schema.json` — JSON Schema for map-render configuration.

## Pattern

Files are regenerated by `npm run filetypes` from `src/opcodes/*.jsonc`. Do not edit by hand.
