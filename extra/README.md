# Extra

Ad-hoc scripts, format research, audio samples, and scratch artifacts.

## Files

- `JAGA_FORMAT_ANALYSIS.md` — Reverse-engineering notes on Jagex Audio (JAGA/Ogg Vorbis) streaming format.
- `mudclient-2003rsc.js` — Legacy 2003 RSC mudclient JS extract.
- `jaga_track_000.ogg` — Sample JAGA audio track.
- `dbrows.json` — DB table/row manifest.
- `manifest_breakdown.json` — Build manifest analysis.
- `build_manifest.js`, `dump_extra.js`, `extrasmap_decoder.ts`, `inspect_format.js`, `scan_cooldowns.js`, `search_hex_names*.js`, `search_items.js`, `test_decoder.ts`, `test_actionables_pipeline.ts` — Debug/inspection scripts.
- `Tao Of Jeet Kune Do.pdf` — Reference PDF.

### Sub-folders

- `items/` — Bulk item-validation artifacts (`pass-*.hexerr.json`, ~61k files).

## Usage

Research and debugging only. Not part of the core runtime.
